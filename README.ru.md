# free-seo-mcp: бесплатный MCP-сервер для подбора ключевых слов

[English version](README.md)

Сбор семантики для Claude, Cursor и любого MCP-клиента без бюджета. Поисковые подсказки,
Google Trends, реальная частота из Bing, треды Reddit и sitemap конкурентов в одном сервере.
Подписка на Ahrefs, Semrush или DataForSEO не нужна.

## Что можно попросить агента

> Расширь «кроссовки для бега» на русском и английском, оцени частоты относительно «беговые
> кроссовки», раздели на ВЧ/СЧ/НЧ и сохрани в проект `shoes`.

> Вытащи все URL из sitemap конкурента и сделай структуру его 10 главных страниц.

> Найди на Reddit треды, где ругают беговые кроссовки, и выпиши их формулировки.

## Зачем

Точную частоту Google показывает только рекламодателям с расходами. Платные SEO-сервисы
продают оценку этой цифры. free-seo-mcp считает свою оценку по бесплатным источникам:

| Источник | Что даёт |
|---|---|
| Подсказки Google, YouTube, Bing, DuckDuckGo | Фразы, которые вводят люди, с баллом по позиции и повторам |
| Google Trends | Соотношение спроса, растущие запросы, спрос по странам |
| Bing Webmaster API | Реальные показы по неделям (бесплатный ключ) |
| Reddit | Слова покупателей, вопросы, возражения |
| Сайты конкурентов | URL из sitemap, title, description, заголовки h1–h3 |

`estimate_volumes` сравнивает каждый запрос с одним якорем в Google Trends. Якорь получает
абсолютное число: ваше или показы Bing, умноженные на коэффициент. На каждый запрос вы получаете
оценку частоты в месяц, уровень ВЧ/СЧ/НЧ, степень уверенности и способ расчёта.

## Инструменты

| Инструмент | Что делает |
|---|---|
| `suggest` | Подсказки одного движка с позициями |
| `expand_alphabet` | Сид плюс каждая буква алфавита, с баллами |
| `expand_questions` | Вопросительные приставки языка (как, почему, что такое...) |
| `expand_multilingual` | Один сид на нескольких локалях `hl:gl` |
| `trends_compare` | До 5 запросов на одной шкале 0–100 |
| `trends_related` | Топовые и растущие связанные запросы |
| `trends_by_region` | Спрос по странам и регионам |
| `bing_keyword` | Показы Bing за период |
| `bing_related_keywords` | Связанные запросы с показами |
| `bing_keyword_history` | Показы по неделям |
| `estimate_volumes` | Оценка частоты и уровень для списка запросов |
| `reddit_search` | Треды с рейтингом, числом комментариев и фрагментом |
| `sitemap_urls` | Все URL из sitemap сайта |
| `page_outline` | Title, meta description, заголовки, число слов |
| `keywords_save`, `keywords_load` | CSV-хранилище запросов по проекту и языку |

Prompt `keyword_research_workflow` ведёт агента по шагам: сиды, расширение, оценка, кластеры,
сохранение.

Алфавиты и вопросительные приставки есть для русского, английского, испанского, португальского,
немецкого, французского и итальянского. Подсказки и Trends работают с любой парой `hl:gl`.

## Быстрый старт

Поставьте [uv](https://docs.astral.sh/uv/), затем:

```bash
git clone https://github.com/JohnWayneeee/free-seo-mcp.git
cd free-seo-mcp
uv sync
```

Claude Code:

```bash
claude mcp add free-seo -- uv run --directory /path/to/free-seo-mcp free-seo-mcp
```

Claude Desktop, Cursor, Windsurf: JSON-конфиг в [README.md](README.md#quick-start).

## Настройки

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `FREE_SEO_BING_API_KEY` | нет | Включает инструменты Bing и оценку по Bing |
| `FREE_SEO_DATA_DIR` | `./seo-data` | CSV с запросами и кэш |
| `FREE_SEO_MIN_DELAY` | `0.4` | Пауза между запросами к одному хосту, сек |
| `FREE_SEO_PROXY` | нет | HTTP(S)-прокси для всех запросов |
| `FREE_SEO_CACHE_TTL_DAYS` | `7` | Срок жизни кэша |

Ключ Bing: войдите в Bing Webmaster Tools, добавьте и подтвердите свой сайт, откройте Settings,
затем API access, и сгенерируйте ключ.

## Ограничения

- Уровням доверяйте больше, чем точным числам.
- Google Trends округляет редкие запросы до 0. Сервер помечает их как «меньше 1% якоря».
- Подсказки, Trends и Reddit работают через неофициальные эндпоинты с лимитами. Сервер держит
  паузы, отступает при HTTP 429 и кэширует ответы на диске. Капчу он не решает.
- Из некоторых сетей Reddit отвечает 403. Тогда задайте `FREE_SEO_PROXY`.
